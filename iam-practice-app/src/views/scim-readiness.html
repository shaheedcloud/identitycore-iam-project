Phase 6

SCIM Users and Groups Endpoints

Phase 6 adds a local SCIM 2.0 Groups endpoint simulation alongside the existing Users endpoint for learning how identity providers provision application identities and memberships.

SCIM provisioning requires Authorization: Bearer <token>. The token is local-only, must stay in an uncommitted .env file, and is never returned by the app.
