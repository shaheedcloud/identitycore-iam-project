SCIM users and groups

Local SCIM 2.0 endpoints model how identity providers provision application identities and memberships.

SCIM bearer tokens belong only in an uncommitted local .env file and are never returned by the app.
IAM concept: Provisioning creates and updates accounts. Authentication still happens separately through local login, OIDC, or SAML.
  • Users endpoint: create, replace, patch, deactivate
  • Groups endpoint: create, replace, patch membership, delete
  • Data resets when the server restarts
