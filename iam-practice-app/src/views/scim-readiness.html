Phase 5

SCIM Users Endpoint

Phase 5 adds a local SCIM 2.0 Users endpoint simulation for learning how identity providers provision, update, and deactivate application users.

SCIM user provisioning requires Authorization: Bearer <token>. The token is local-only, must stay in an uncommitted .env file, and is never returned by the app.
