Phase 4

Protected API JWT Validation

Phase 4 protects selected API routes with bearer-token validation. Browser login still uses either local dummy login or Entra OIDC session login.

Protected API calls must send Authorization: Bearer <token>. The app validates issuer, audience, signature, and expiration before returning protected API data.
