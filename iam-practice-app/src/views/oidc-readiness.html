Phase 14 OIDC local practice

Entra and Okta OIDC local practice

Microsoft Entra ID and Okta OIDC login can run only when complete values are present in a local uncommitted .env file.

Local dummy login still works. OIDC-authenticated users are intentionally assigned the safe local standard_user role and external claims or groups do not grant admin access.
IAM concept: OIDC authenticates the browser user. IdentityCore stores only a conservative local profile and a presence-only claim summary. Raw tokens are not stored, logged, displayed, or returned by APIs.
  • Configured values belong only in iam-practice-app/.env.
  • .env.example must stay placeholder-only.
  • Dashboard provider context should show the Entra or Okta lab name after login.
