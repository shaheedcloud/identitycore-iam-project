Orientation

How to use this path

IdentityCore is a local-first IAM practice app, not a production IAM system. Use each module to explain one IAM concept, open the linked page, then practice describing what the module proves and what it deliberately does not do.

Core principle: external authentication proves identity. IdentityCore local RBAC controls IdentityCore access. Future cloud or provider access requires separate explicit authorization design.

Learning map

Concept connections

  • Authentication creates a safe local session.
  • Claims describe identity signals.
  • Role mapping explains how signals become local roles.
  • RBAC decides access to protected IdentityCore pages.
  • Federation pages explain OIDC, JWT, and SAML boundaries.
  • SCIM provisions records but does not log users in.
  • JML creates lifecycle evidence for identity changes.
  • Audit pages help explain troubleshooting evidence safely.
  • AWS readiness stays separate from IdentityCore authorization.
Every link on this page points to an existing local IdentityCore page. Unavailable production behavior is marked as simulated, readiness-only, or not connected.
