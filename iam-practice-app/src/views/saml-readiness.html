SAML Concepts

  • Identity Provider: authenticates the user and sends a SAML assertion.
  • Service Provider: this app, which receives the assertion at the ACS URL.
  • ACS URL: http://localhost:3000/auth/saml/callback
  • Entity ID: http://localhost:3000/saml/metadata

SAML Routes

  • GET /auth/saml/login
  • POST /auth/saml/callback
  • GET /saml/metadata
  • GET /api/saml/status
