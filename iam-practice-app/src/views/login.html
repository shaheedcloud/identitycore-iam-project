IdentityCore is a learning app, not a production IAM system. Real IdP values belong only in a local uncommitted .env file.

What you can practice

Local login, least privilege, protected routes, simulated claims, SCIM, JML, SAML, OIDC readiness, and audit evidence.

What stays off limits

No production tenants, no cloud deployment, no real secrets, no raw tokens, and no external identity calls by default.
